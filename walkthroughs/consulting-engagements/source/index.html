How these were built

All three documents share one stylesheet (walkthrough.css) and pull screenshots from the same screenshots/ folder, so updates to a screen propagate everywhere it appears. The wording is tuned per audience — the customer doc never references OnFrontiers' internal queue, the expert doc never references governance.

If you spot a screen that needs updating, swap the file in screenshots/ and every walkthrough that references it will reflect the change.
